## چه چیزی ساخته شد

### کنسول Elasticsearch — ویزارد راه‌اندازی + گزارش عملیات
- **ویزارد سه‌گامی** بالای صفحه: ① ساخت/بررسی ایندکس پشت alias ← ② بازایندکس اختیاری از ایندکس مبدأ ← ③ سوییچ اتمی alias. هر گام همان APIهای موجود کنسول را صدا می‌زند؛ وضعیت هر گام زنده نمایش داده می‌شود (در انتظار/در حال اجرا/انجام شد/ناموفق/ردشده) و اگر گامی شکست بخورد زنجیره متوقف می‌شود.
- **گزارش عملیات**: هر اجرای ویزارد و همهٔ اکشن‌های صفحه (ensure/reindex/alias/حذف) با زمان، نتیجه (موفق/خطا) و پاسخ کامل ثبت می‌شوند (۱۰۰ مورد اخیر این نشست؛ نسخهٔ ماندگار در گزارش حسابرسی).
- با ES خاموش، ویزارد به‌جای crash خطای دقیق را در گام و log نشان می‌دهد — تست زنده شد.

### کنسول ایجنت — تاریخچهٔ مکالمه + پاک‌کردن
- گفتگو حالا به‌صورت **رشتهٔ حباب‌های کاربر/دستیار** نمایش داده می‌شود؛ متادیتای هر پاسخ (پله، تأخیر، cache، تعداد ارجاع) روی همان حباب.
- تاریخچه **به‌ازای هر فروشگاه** در مرورگر ذخیره می‌شود (۴۰ پیام اخیر) و بعد از reload می‌ماند؛ دکمهٔ «پاک‌کردن تاریخچه» در هر دو محل (زیر ورودی و کارت نشست).

### ویجت — پیش‌نمایش واقعی
- همان **`widget/v1.js` واقعی** که فروشگاه‌ها embed می‌کنند، در iframe ایزوله (`sandbox="allow-scripts"`) با srcdoc بارگذاری می‌شود و تنظیمات پیش‌فرض ذخیره‌شده را از API می‌خواند — پس از هر ذخیره خودکار refresh می‌شود + دکمهٔ «بارگذاری مجدد». پیش‌نمایش شماتیک قبلی هم برای مقایسهٔ سریع باقی ماند.
- تست زنده: اسکریپت loader داخل iframe واقعاً اجرا و launcher مونت شد.

### مترادف‌ها
- placeholder ادیتور و بلوک مثال از رشته‌های hardcoded به i18n (fa+en) منتقل شدند.

### پرچم‌های ویژگی
- migration `0014`: ستون `updated_by` — تغییر هر پرچم با **ایمیل ادمین تغییردهنده** ثبت و کنار «آخرین تغییر» (تاریخ شمسی) نمایش داده می‌شود؛ audit هم با همان actor ثبت می‌شود.
- ستون «اثر فعال‌بودن»: توضیح فارسی/انگلیسی دقیق برای هر ۴ پرچم شناخته‌شده (پرچم ناشناس → توضیح DB).

### گسترش QA خودکار (fe-qa)
- **responsive-check**: ۷ مسیر ادمین باقی‌مانده اضافه شد (elasticsearch، agent، widget، synonyms، queue، contact، operators) → حالا **هر ۲۰ صفحهٔ ادمین** در ۳۷۵px و ۱۲۸۰px بررسی می‌شوند.
- **functional-check**: ۴ چک جدید — toggle پرچم (رفت‌وبرگشت واقعی state)، رندر ویزارد ES، و embed واقعی loader در iframe ویجت.
- **a11y-check**: بخش ادمین با ورود واقعی اضافه شد (۸ صفحهٔ کلیدی). اولین اجرا یک نقص واقعی پیدا کرد — selectهای فیلتر بدون نام دسترس‌پذیر — که در **همهٔ** صفحات ادمین (نه فقط صفحهٔ گزارش‌شده) با `aria-label` رفع شد.

## دستورات تست روی ویندوز (محیط شما)

```powershell
# 1) مهاجرت جدید
$env:PG_DSN = "postgresql://acip:<pass>@localhost:5433/acip"
python scripts/apply_migrations.py    # باید 0014_flag_updated_by را اعمال کند

# 2) تست دستی UI → http://localhost:3000/admin
#    الستیک‌سرچ: «اجرای ویزارد» (با ES روشنِ خودتان: هر ۳ گام سبز؛ نتیجه در «گزارش عملیات»)
#    کنسول ایجنت: چند پیام بفرستید → صفحه را refresh کنید (تاریخچه می‌ماند) → «پاک‌کردن تاریخچه»
#    تنظیمات ویجت: تغییری بدهید و ذخیره کنید → پیش‌نمایش واقعی خودکار تازه می‌شود
#    پرچم‌ها: یکی را toggle کنید → ایمیل شما در «آخرین تغییر» ثبت می‌شود

# 3) QA خودکار (بعد از build و اجرای web+API)
cd apps/web
$env:ADMIN_TOKEN = "<توکن>"
node scripts/fe-qa/functional-check.cjs
node scripts/fe-qa/responsive-check.cjs
node scripts/fe-qa/a11y-check.cjs
```
