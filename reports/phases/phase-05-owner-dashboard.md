## چه چیزی ساخته شد

### Backend — endpointهای جدید (`services/api/routers/tenant.py` + `billing.py`)

| Endpoint | شرح |
|---|---|
| `GET /tenant/sync-status` | وضعیت همگام‌سازی هر منبع (آخرین اجرا/وضعیت/watermark) + **شمار زندهٔ محصولات ایندکس‌شده از ES** — با تفکیک درست «خالی» از «موتور جست‌وجو خاموش» (ping جدا از count) |
| `POST /tenant/sync/trigger` | «همگام‌سازی الان»: درخواست فوراً در `sync_state` ثبت (queued) و تسک Celery صف می‌شود؛ worker بعد از اجرا آن را ok می‌کند |
| `POST /tenant/search-test` | تست زندهٔ جست‌وجو با همان retrieval هیبریدی ویجت، محدود به فروشگاهِ خود کاربر؛ با ES خاموش degrade می‌شود نه crash |
| `GET /tenant/assistant-status` | سلامت دستیار برای مالک (پرچم پلتفرم/پیکربندی LLM/تعداد ایندکس) — **بدون افشای هیچ URL داخلی** |
| `POST /tenant/team/resend` | ارسال مجدد دعوتِ در انتظار با توکن تازهٔ ۷روزه (لینک‌های قبلی باطل می‌شوند) |
| `GET /tenant/billing/invoices/{number}/html` | فاکتور HTML مستقل و قابل چاپ (Print مرورگر → PDF)، فقط در محدودهٔ فروشگاه خود کاربر |
| degraded flags | `/tenant/analytics` · `/tenant/insight` · `/tenant/zero-results` با ES خاموش پاسخ ۲۰۰ + `degraded: true` می‌دهند |
| worker | تسک `reconcile_tenant` حالا اجرایش را واقعاً در `sync_state` ثبت می‌کند (queued → ok قابل مشاهده) |

### صفحات داشبورد

| صفحه | تغییر |
|---|---|
| **نمای کلی** | هشدار اعتبار کم (<۱۰٪ سقف با لینک خرید) + **چک‌لیست راه‌اندازی زنده** (تأیید ایمیل/اتصال فروشگاه/همگام‌سازی/کلید ویجت — از وضعیت واقعی تیک می‌خورد، هر گام لینک مقصد دارد) |
| **کاتالوگ** | کارت وضعیت همگام‌سازی (تعداد ایندکس + آخرین اجرا + جدول منابع) + دکمهٔ **«همگام‌سازی الان»** + پیام degraded برای ES خاموش |
| **تنظیم جست‌وجو** | **تست زندهٔ جست‌وجو** (همان جست‌وجوی ویجت) + دکمهٔ «امتحان» روی هر عبارت بدون‌نتیجه که مستقیم تستش می‌کند |
| **دستیار** | کارت وضعیت (پرچم پلتفرم/مدل زبانی/ایندکس) + راهنمای حالت خالی با لینک اتصال کاتالوگ |
| **تحلیل / تبدیل / گفت‌وگو** | بنر degraded به‌جای صفحهٔ گیج‌کننده وقتی ES خاموش است |
| **سرنخ‌ها** | چیپ‌های فیلتر وضعیت با شمارش + **انتخاب گروهی و اعمال وضعیت یکجا** (checkbox + انتخاب همه) |
| **پلن و صورت‌حساب** | **پنل پیش‌نمایش ارتقا** (قیمت پایه − اعتبار زمان استفاده‌نشده = مبلغ قابل پرداخت، با تأیید/انصراف صریح به‌جای confirm مرورگر) + **دانلود فاکتور HTML** برای هر فاکتور |
| **ویجت و برند** | **تست زندهٔ ویجت در همین صفحه**: loader واقعی در iframe ایزوله؛ با واردکردن کلید ویجت، جست‌وجو/چت واقعاً به فروشگاه وصل می‌شود (کلید فقط در مرورگر می‌ماند) |
| **پایگاه دانش** | جست‌وجو در عنوان و متن مقاله‌ها |
| **تیم** | نشان «در انتظار» + شمارندهٔ دعوت‌های معلق + دکمهٔ **«ارسال مجدد دعوت»** |
| **تنظیمات** | **ویزارد اتصال OpenCart/WooCommerce**: ① مشخصات فروشگاه ② نصب افزونه + کلید sync ③ بررسی اتصال — هر گام از وضعیت واقعی تیک می‌خورد |
