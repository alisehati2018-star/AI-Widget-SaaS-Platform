# ممیزی جامع سیستم ویترین — صفحه‌به‌صفحه + امتیازدهی

تاریخ: ۱۴۰۵/۰۴/۱۲ · شاخه: `claude/gallant-shannon-8b31td`

## روش ممیزی

- **بصری:** ۴۳ اسکرین‌شات زنده با مرورگر واقعی (۷ صفحهٔ عمومی + ۲۰ ادمین + ۱۶ داشبورد فروشنده، فارسی/RTL، با ورود واقعی) و بازبینی نمونه‌ها
- **کارکردی:** جاروی خودکار ۳۶ صفحه (heading/error/JS) + گیت‌های fe-qa (functional/responsive/a11y/i18n) + کل تست‌ها (۱۶۸ پاس)
- **زنجیرهٔ داده:** تست زندهٔ «تغییر در داشبورد ← ذخیره در PG ← انعکاس سمت سایت»: تنظیمات ویجت فارسی → `/v1/widget/config` ✓ · پلن جدید ادمین → صفحهٔ عمومی `/plans` ✓ · (چرخهٔ pull فروشگاه، پرداخت، KPI قبلاً E2E تست شده‌اند)
- **ساختاری:** مرور معماری، schema، امنیت، تست، عملیات

## ⛔ باگ بحرانی — در همین ممیزی پیدا و رفع شد

**ذخیرهٔ تنظیمات فارسی ویجت ۵۰۰ می‌داد.** کدک jsonb با `json.dumps` پیش‌فرض متن فارسی را به `\uXXXX` تبدیل می‌کرد و روی دیتابیس‌هایی که encoding سرورشان یونیکد نیست (مثل cluster قدیمی SQL_ASCII) درج شکست می‌خورد؛ چون همهٔ تست‌های قبلی مقدار ASCII ذخیره کرده بودند، دیده نشده بود. **رفع:** `ensure_ascii=False` در codec (`packages/acip_core/clients/postgres.py`) — حالا «پیام خوش‌آمد فارسی» از داشبورد ذخیره و دقیقاً در config ویجت سمت سایت دیده می‌شود (تأیید زنده). روی PG تولید (UTF8) هم payload کوچک‌تر می‌شود. کل ۱۶۸ تست بعد از رفع سبز.
